# LinguaPoint — языковая школа

**LinguaPoint** — учебный веб-проект на Django, представляющий сайт языковой школы с каталогом курсов английского, испанского и немецкого языков.

Проект позволяет пользователям знакомиться с курсами, выбирать подходящие учебные группы, отправлять заявки и управлять своим личным кабинетом.

## 1. Основные возможности

- Просмотр каталога языковых курсов.
- Поиск курсов по названию.
- Фильтрация по языку и уровню владения.
- Просмотр подробной информации о курсах.
- Просмотр списка преподавателей.
- Регистрация и авторизация пользователей.
- Отправка заявок на обучение.
- Личный кабинет пользователя.
- Редактирование профиля.
- Просмотр собственных заявок.
- Адаптивный интерфейс для компьютеров, планшетов и смартфонов.
- Клиентская валидация форм.
- Динамический поиск курсов с использованием JavaScript и JSON API.

## 2. Используемые технологии

- **Python** — основной язык программирования.
- **Django** — серверный веб-фреймворк.
- **SQLite** — база данных.
- **HTML5** — структура страниц.
- **CSS3** — оформление и адаптивная вёрстка.
- **JavaScript** — интерактивность и динамическая загрузка данных.
- **Git и GitHub** — контроль версий и хранение исходного кода.

## 4. Установка и запуск

### Требования

- Python 3.10 или новее.
- pip.
- Git (для получения исходного кода).

### Клонирование проекта

```powershell
git clone https://github.com/gbjkhghch-dot/LinguaPoint.git
cd LinguaPoint
```

### Создание виртуального окружения

```powershell
python -m venv venv
```

### Активация виртуального окружения

```powershell
.\venv\Scripts\Activate.ps1
```

### Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

### Применение миграций

```powershell
python manage.py migrate
```

### Загрузка демонстрационных данных

```powershell
python manage.py loaddata fixtures/seed.json
```

Если база уже заполнена, перед повторной загрузкой фикстуры следует проверить содержимое базы данных.

### Запуск сервера

```powershell
python manage.py runserver
```

После запуска сайт будет доступен по адресу:

http://127.0.0.1:8000/
