# Проверка перед сдачей (занятия 7–9)

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py loaddata fixtures/seed.json
python manage.py check
python manage.py test
python manage.py runserver
```

Если данные уже загружены, повторно `loaddata` выполнять не нужно.

## Проверка вручную

1. Открыть главную, каталог, карточку курса, заявку, поиск, преподавателей, регистрацию, вход и кабинет.
2. Открыть DevTools, проверить ширины 360, 768, 1024 и 1440 px. Убедиться в отсутствии горизонтальной прокрутки, работоспособности меню-бургера, читаемости текста.
3. Проверить поиск и фильтры в каталоге без перезагрузки: статус «Загрузка курсов…», список результатов, пустую выдачу, обработку ошибки сети.
4. Отправить некорректную заявку (имя, телефон, e-mail, согласие) и корректную заявку; проверить ошибки и сохранение данных.
5. Проверить консоль браузера на каждой странице.
6. Сохранить HTML каждой страницы и проверить на https://validator.w3.org/ ; CSS — на https://jigsaw.w3.org/css-validator/ .
7. Запустить Chrome Lighthouse на мобильной эмуляции; Performance и Accessibility должны быть >= 85. **Результаты в этом архиве не заявляются как пройденные**.
8. Сделать скриншоты всех страниц при 375 и 1440 px и сравнить 2–3 страницы с макетами из занятия 6.
9. Создать собственный Git-репозиторий, вести осмысленные коммиты во время реальной работы; нельзя задним числом выдавать историю за три учебных дня.

## Примечания

Проект использует модели занятия 5; каталог содержит пагинацию по 20 записей. В шаблоне `_cards.html` используются `date`, `truncatechars`, `floatformat`. Изображения в интерфейсе не используются: декоративные элементы выполнены CSS, поэтому требования к атрибутам `width`, `height`, `loading=lazy` неприменимы к текущим шаблонам.
